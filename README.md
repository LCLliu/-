# 五术研习

以「山医命相卜」为纲的中国传统术数文化学习站。当前版本是**界面骨架 + 十五篇内容初稿**：信息架构、视觉系统和占位页面已完成，共通基础「阴阳五行」与医门类藏象、经络、气血津液、四诊、辨证已开放，其余知识内容尚未接入。

> 「五术研习」为工作名，可随时更换。

## 技术栈

- Astro 7 + TypeScript
- Tailwind CSS 4（已接入 `@tailwindcss/vite`）
- 原生 CSS 设计令牌与组件样式
- 静态输出（`output: "static"`）
- 计划中：MDX 内容集合、React 岛、Fuse.js 搜索、localStorage 学习进度

## 本地运行

环境要求：Node.js 22 及以上（当前环境为 Node 24）。

```bash
npm install
npm run dev
```

打开 <http://localhost:4321/>。

```bash
npm run check    # Astro 类型检查
npm run build    # 构建到 dist/
npm run preview  # 预览构建产物
```

当前只有一个开发服务器，不需要启动后端、数据库或其他进程。

## 目录结构

```text
src/
├─ components/          # 导航、五术关系图、门类卡片、占位组件
├─ data/
│  ├─ disciplines.ts    # 五门配置：slug、名称、主色、规划章节
│  ├─ navigation.ts
│  └─ site.ts
├─ layouts/             # BaseLayout
├─ pages/               # 首页、五门动态路由、顶层占位页、404
└─ styles/global.css    # 设计令牌与全站样式
```

五门页面共用 `src/pages/[discipline]/index.astro` 一个模板，门类信息来自 `src/data/disciplines.ts`；后续增加内容页或新增门类时，不需要复制五套页面代码。

## 知识资料

- `materials/医/`：19 本人纪系列 PDF，约 700MB；本地原始资料，已加入 `.gitignore`
- `knowledge/医/`：书籍索引、阅读定位与原创整理稿
  - `README.md`：19 本书的索引
  - `阴阳五行.md`：基于《黄帝内经》上册 p.44–52、p.77–83 的整理
  - `藏象.md`：基于《灵兰秘典论》《六节藏象论》《五脏别论》的整理
  - `十二经络.md`：基于《针灸篇》p.18–27、p.46–181 的整理
  - `奇经八脉.md`：基于《针灸篇》p.182–186 的整理
  - `络脉.md`：基于《针灸篇》p.182–183 与《灵枢·经脉》的整理
  - `任督穴位.md`：基于《针灸篇》p.28–45 的任脉 24 穴、督脉 28 穴索引
  - `井荥俞原经合.md`：基于《针灸篇》p.18–27 的十二经五输穴表
  - `气血津液.md`：基于《经脉别论》《决气》《营卫生会》《调经论》的整理
  - `诊法.md`：四诊总览、合参与边界
  - `望诊.md`：望神、望色、望形、望态与舌诊基础
  - `闻诊.md`：声息、气味与闻诊边界
  - `问诊.md`：九类问诊清单与顺序
  - `切诊.md`：脉诊、按诊与切诊边界
  - `四诊合参案例.md`：三个虚构案例与复盘清单
  - `辨证与治法.md`：症证病、辨证框架、治法边界

## 设计说明

- 纸墨米白为底，墨色正文，朱砂强调；五门各用一个低饱和辅色区分。
- 首页五术关系图是视觉导航，下方门类卡片提供同一组可访问链接。
- 当前只有阴阳五行、藏象、经络链、气血津液、四诊、四诊合参案例与辨证与治法十五篇知识页开放初稿；其余知识页仍为结构占位，没有编写未经核对的医案、方剂或术数结论。
- 页脚与关于页已声明内容边界：不提供医疗诊断、算命或风水服务。
