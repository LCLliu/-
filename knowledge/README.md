# 知识库

这里是项目的知识整理区。

- `医/README.md`：医门类的原始资料索引、阅读定位和整理计划
- 原始 PDF：放在项目根目录的 `materials/医/`，已加入 `.gitignore`，不进入 Git 仓库
- 约定：`materials/` 放原始资料，`knowledge/` 放索引和原创整理稿；每个主题一个 Markdown 文件

当前医门类优先整理：阴阳五行、藏象、经络、诊法。

已产出：

- `医/阴阳五行.md`：基于《黄帝内经》上册 p.44–52、p.77–83 的阅读整理
- `医/藏象.md`：基于《灵兰秘典论》《六节藏象论》《五脏别论》的阅读整理
- `医/十二经络.md`：基于《针灸篇》p.18–27、p.46–181 的阅读整理
- `医/奇经八脉.md`：基于《针灸篇》p.182–186 的阅读整理
- `医/络脉.md`：基于《针灸篇》p.182–183 与《灵枢·经脉》的阅读整理
- `医/任督穴位.md`：基于《针灸篇》p.28–45 的任脉 24 穴、督脉 28 穴索引
- `医/井荥俞原经合.md`：基于《针灸篇》p.18–27 的十二经五输穴表与取穴规律
- `医/气血津液.md`：基于《经脉别论》《决气》《营卫生会》《调经论》的阅读整理
