# 八纲辨证：四对坐标

## 一句话结论

八纲把四诊线索压缩成四对坐标：阴阳、表里、寒热、虚实。它先回答病位深浅、病性寒热、正邪盛衰，再用阴阳收拢总方向；不是八个可以逐个勾选的标签。

## 原文骨架

> 善诊者，察色按脉，先别阴阳。（《素问·阴阳应象大论》）

> 阳虚则外寒，阴虚则内热；阳盛则外热，阴盛则内寒。（《素问·调经论》）

> 邪气盛则实，精气夺则虚。（《素问·通评虚实论》）

> 风雨之伤人也，先客于皮肤，传入于孙脉，孙脉满则传入于络脉，络脉满则输于大经脉。（《素问·调经论》）

## 四对坐标

| 纲 | 看什么 | 两端 |
| --- | --- | --- |
| 阴阳 | 总方向 | 阴证 / 阳证 |
| 表里 | 病位深浅 | 表 / 里（含半表半里） |
| 寒热 | 病性 | 寒 / 热 |
| 虚实 | 正邪盛衰 | 虚 / 实 |

- 阴阳为总纲，但不宜机械地把每个具体证候硬塞进“纯阴”或“纯阳”。
- 表、热、实一般偏阳；里、寒、虚一般偏阴。这是归类倾向，不是算术公式。
- 八纲回答的是“位置、性质、力量对比”，不直接回答“哪个脏腑”。

## 表里

- 表：体表、肌肤、经络浅层。外感初起常见恶寒发热、头身痛、脉浮。
- 里：脏腑、气血深层。里证范围很大，必须再结合脏腑或其他框架定位。
- 半表半里：邪不在表、也未完全入里，传统上以少阳病为代表，常见寒热往来、口苦、咽干、目眩、脉弦。
- 传变：表邪不解可以入里；里虚也可以兼表。表里是相对深浅，不是固定解剖位置。
- 《调经论》讲风雨伤人由皮肤→孙脉→络脉→大经脉，是“由表入里”的传变模型。

## 寒热

- 寒：阳气不足，或阴寒内盛。常见畏寒喜暖、口不渴或喜热饮、小便清长、大便稀溏、舌淡苔白、脉迟或紧。
- 热：阳盛，或阴虚内热。常见发热喜凉、口渴喜冷饮、小便短赤、大便干结、舌红苔黄、脉数。
- 《调经论》把寒热与阴阳盛衰对应起来：阳虚外寒、阴虚内热、阳盛外热、阴盛内寒。
- 寒热可以错杂，也可能出现真假。真假之辨不能靠单一症状，要结合舌脉、喜恶、二便、病程与整体状态。

## 虚实

- 实：邪气盛，正气尚未大伤。常见病程较短、声高气粗、痛而拒按、脉实有力。
- 虚：正气不足。常见病程较长、声低乏力、痛而喜按、脉虚无力。
- 《通评虚实论》的定义是“邪气盛则实，精气夺则虚”；《调经论》又有“有者为实，无者为虚”的简捷说法。
- 虚实可以夹杂：本虚标实、正虚邪恋都很常见。不能把“虚”简单理解成“没病”，也不能把“实”简单理解成“病重”。

## 阴阳

- 阴阳是总纲：把表里、寒热、虚实三对坐标收拢成一个总方向。
- 阴阳不是固定标签。表寒证同时有“表”与“寒”，不能因为“表属阳”就判成阳证。
- 阴阳可以互相转化：寒证日久可以化热，热证日久可以伤阴；阴虚可以阳亢，阳虚可以阴盛。
- 具体证候的阴阳归属，要看整体证据，不靠单个症状。

## 常见组合

| 组合 | 常见线索（教学示例） | 读法 |
| --- | --- | --- |
| 表寒 | 恶寒重、发热轻、无汗、头身痛、脉浮紧 | 病位在表，病性偏寒 |
| 表热 | 发热重、恶寒轻、口渴、咽痛、脉浮数 | 病位在表，病性偏热 |
| 里实热 | 高热、口渴、腹满痛拒按、便秘、舌红苔黄、脉数有力 | 邪盛于里，正未大虚 |
| 里虚寒 | 畏寒肢冷、腹痛喜按、便溏、舌淡、脉沉迟无力 | 阳气不足，病位在里 |
| 虚实夹杂 | 久病乏力，同时有痰、瘀、积滞等线索 | 正虚与邪实并存 |

这些只是组合方式的示例，不是自我诊断表。真实辨证还要看病程、体质、舌脉与鉴别诊断。

## 一个虚构教学案例

- 情境：淋雨受凉后次日不适（人物与情节均为虚构）。
- 线索：恶寒重、发热轻、无汗、头身疼痛、鼻塞流清涕；舌淡红、苔薄白，脉浮紧。
- 八纲读法：病位在表；病性偏寒；正邪关系以邪实为主，未见明显正虚；阴阳不单独硬判，先保留“表寒”这一具体结论。
- 鉴别：若汗出、脉浮缓，要考虑表虚；若发热重、咽痛、脉浮数，要考虑表热；若出现高热、口渴、便秘、脉数有力，则要警惕病邪入里。
- 边界：这是课堂练习，不构成诊断，也不给出治疗。

## 常见误区

1. 把八纲当成八种病：八纲是坐标，不是疾病分类。
2. 把阴阳当成万能标签：具体证候往往寒热虚实交错，不能机械二分。
3. 凭单一症状定寒热虚实：口苦不一定是热，畏寒不一定是寒，必须合参。
4. 用八纲替代脏腑、六经等框架：八纲定总方向，定位到脏腑或病层还需要另一层框架。
