## 阅读与整理顺序

1. **黄帝内经上册**：先读 p.44 阴阳应象大论、p.77 六节藏象论，整理阴阳五行与藏象笔记。
2. **黄帝内经中下册 + 注解**：补经络、诊法、养生。
3. **伤寒论 / 金匮 / 神农本草 / 针灸**：按六经、杂病、本草、经络四条线整理。
4. **医案四册**：作为案例库，只做辨证思路复盘，不作诊断建议。

## 整理约定

- 一个主题一个文件，例如 `knowledge/医/阴阳五行.md`
- 每篇注明：参考书目、章节、书内页码、原文/摘要/个人理解
- 经典原文可短引；近代讲义只做概括，不复制整页或长段
- 医学内容统一声明：传统理论展示，不构成诊断、处方或治疗建议
