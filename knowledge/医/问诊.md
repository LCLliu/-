# 问诊：把生活史放回整体

## 一句话结论

问诊不是症状搜索，而是通过寒热、汗、头身、饮食、二便、睡眠、情志、月经、既往史与用药，把一个人的生活史放回整体。问得全，才有合参的基础。

## 原文骨架

> 诊病不问其始，忧患饮食之失节，起居之过度，或伤于毒，不先言此，卒持寸口，何病能中？（《素问·征四失论》）

## 问诊清单

| 类别 | 问什么 | 目的 |
| --- | --- | --- |
| 寒热 | 怕冷、怕热、寒热往来、手足温度 | 看寒热倾向与表里 |
| 汗 | 有无汗、盗汗、自汗、局部汗 | 看津液与表里 |
| 头身 | 头痛、头晕、身痛、腰背不适 | 定位与性质线索 |
| 饮食 | 食欲、口味、饮水、冷热偏好 | 看脾胃与津液 |
| 二便 | 大便次数/性状、小便颜色/频次 | 看传化与水液 |
| 睡眠 | 入睡、易醒、多梦、嗜睡 | 看阴阳与神志 |
| 情志 | 压力、情绪、思虑、惊恐 | 看气机与脏腑关系 |
| 月经 | 周期、量、色、痛经、带下 | 女性问诊的重点 |
| 既往/用药 | 旧病、手术、长期用药、过敏 | 避免遗漏与冲突 |

## 问诊顺序

1. 主诉：最困扰的是什么，持续多久。
2. 现病史：起病、变化、加重/缓解因素。
3. 生活史：饮食、睡眠、二便、情志、劳逸。
4. 既往史与用药：旧病、手术、长期药物、过敏。
5. 特殊问诊：女性月经、儿童生长发育。
