# 六经辨证案例：六个虚构练习

## 一句话结论

六个案例分别练太阳、少阳、阳明、太阴、少阴、厥阴：先写四诊线索，再对提纲、定六经、过八纲、做鉴别、标待补。重点不是“猜中”，而是把推理过程写清楚。

## 练习模板

| 步骤 | 写什么 |
| --- | --- |
| 四诊 | 望、闻、问、切分别记录，不先写结论 |
| 提纲 | 哪一句提纲最贴近主证 |
| 六经 | 太阳 / 阳明 / 少阳 / 太阴 / 少阴 / 厥阴 |
| 八纲 | 表里、寒热、虚实 |
| 鉴别 | 支持证据、反证、相似证候 |
| 待补 | 缺失信息与现代医学检查 |

## 案例一：恶寒发热（虚构）

- 24 岁，淋雨受凉后次日不适。
- 望：舌淡红，苔薄白。
- 闻：语声略重，无特殊气味。
- 问：恶寒重、发热轻、无汗、头身疼痛、鼻塞流清涕。
- 切：脉浮紧。
- 六经：太阳。
- 八纲：表、寒、实。
- 提纲对应：“脉浮，头项强痛而恶寒。”
- 鉴别：太阳中风可见汗出、脉浮缓；少阳多见寒热往来、口苦、咽干；阳明多见但热不寒、口渴、便秘。
- 待补：体温、咽痛、咳嗽、病程、基础病与用药。
- 边界：虚构案例，不作诊断，不给治疗。

## 案例二：寒热往来（虚构）

- 36 岁，反复寒热 3 天。
- 望：舌边偏红，苔薄白。
- 闻：语声正常，无特殊气味。
- 问：寒热往来、口苦、咽干、目眩、胸胁苦满、默默不欲饮食、心烦。
- 切：脉弦。
- 六经：少阳。
- 八纲：半表半里、偏热；虚实需再辨。
- 提纲对应：“口苦，咽干，目眩也。”
- 鉴别：太阳以恶寒发热、脉浮为主；阳明以但热不寒、腹满便秘为主；太阴以腹满吐利、脉弱为主。
- 待补：体温曲线、黄疸、二便、肝胆与胃肠相关检查。
- 边界：虚构案例，不作诊断，不给治疗。

## 案例三：高热腹满（虚构）

- 40 岁，高热 3 天。
- 望：面红，舌红，苔黄燥。
- 闻：声高气粗。
- 问：不恶寒反恶热、大汗出、口渴喜冷饮、腹满痛拒按、便秘。
- 切：脉洪大有力。
- 六经：阳明。
- 八纲：里、热、实。
- 提纲对应：“阳明之为病，胃家实是也。”
- 鉴别：太阳可见恶寒、脉浮；少阳多见寒热往来、脉弦；少阴热化多见脉细数、心烦不得卧，一般无腹满便秘。
- 待补：脱水程度、感染指标、急腹症鉴别；高热伴腹满痛需及时现代医学评估。
- 边界：虚构案例，不作诊断，不给治疗。

## 案例四：腹满便溏（虚构）

- 52 岁，反复腹满、食少 3 个月。
- 望：舌淡胖，苔白腻。
- 闻：语声偏低，无特殊气味。
- 问：腹满、食不下、大便稀溏、时腹自痛、乏力、畏寒。
- 切：脉弱。
- 六经：太阴。
- 八纲：里、虚寒，兼湿盛。
- 提纲对应：“腹满而吐，食不下，自利益甚，时腹自痛。”
- 鉴别：阳明腹满多痛而拒按、便秘、苔黄；少阴多见脉微细、但欲寐、四肢冷；厥阴多见寒热错杂。
- 待补：体重变化、饮食、二便、电解质、甲状腺功能与胃肠检查。
- 边界：虚构案例，不作诊断，不给治疗。

## 案例五：但欲寐（虚构）

- 68 岁，畏寒、精神差 2 天。
- 望：舌淡，苔白滑。
- 闻：语声低微。
- 问：畏寒蜷卧、四肢冷、但欲寐、下利清谷、小便清长。
- 切：脉微细。
- 六经：少阴（寒化）。
- 八纲：里、虚、寒。
- 提纲对应：“脉微细，但欲寐也。”
- 鉴别：太阴以腹满吐利、脉弱为主；少阴更见心肾虚衰、脉微细、但欲寐、四肢冷；厥阴多见寒热错杂。若心烦不得卧、咽干、脉细数，考虑少阴热化。
- 待补：血压、体温、感染指标、电解质、肾功能、甲状腺功能、心电图；老年患者出现脉微细、下利、精神萎靡需及时现代医学评估。
- 边界：虚构案例，不作诊断，不给治疗。

## 案例六：寒热错杂（虚构）

- 55 岁，反复手足冷、心中疼热、饥不欲食 1 个月。
- 望：舌淡红，苔白黄相兼。
- 闻：语声偏低。
- 问：手足冷、口渴多饮、气上撞心、心中疼热、饥不欲食、食后恶心，大便时干时稀。
- 切：脉弦细。
- 六经：厥阴。
- 八纲：里、寒热错杂、虚实夹杂。
- 提纲对应：“消渴，气上撞心，心中疼热，饥而不欲食。”
- 鉴别：少阳多寒热往来、口苦、胸胁苦满、脉弦；太阴多腹满吐利、脉弱；少阴多脉微细、但欲寐；厥阴的关键是寒热并见。
- 待补：呕吐物、二便、血糖、肝胆胃肠与心血管评估；“消渴、胸中疼热、呕吐”需现代医学评估。
- 边界：虚构案例，不作诊断，不给治疗。
