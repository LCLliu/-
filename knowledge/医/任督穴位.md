# 任督穴位：前后正中线上的两组入口

## 一句话结论

任脉行于前正中，督脉行于后正中；任脉 24 穴、督脉 28 穴。学习时先记线路和分段，再记穴位名，最后才看交会、募穴与传统应用。

## 任脉 24 穴

按从下到上的顺序：

| 区段 | 穴位 |
| --- | --- |
| 会阴 / 下腹 | 会阴、曲骨、中极、关元、石门、气海、阴交、神阙 |
| 上腹 | 水分、下脘、建里、中脘、上脘、巨阙、鸠尾 |
| 胸 | 中庭、膻中、玉堂、紫宫、华盖、璇玑 |
| 颈 / 面 | 天突、廉泉、承浆 |

顺序记忆：会阴 → 曲骨 → 中极 → 关元 → 石门 → 气海 → 阴交 → 神阙 → 水分 → 下脘 → 建里 → 中脘 → 上脘 → 巨阙 → 鸠尾 → 中庭 → 膻中 → 玉堂 → 紫宫 → 华盖 → 璇玑 → 天突 → 廉泉 → 承浆。

## 督脉 28 穴

按从下到上的顺序：

| 区段 | 穴位 |
| --- | --- |
| 骶 / 腰 | 长强、腰俞、腰阳关、命门、悬枢 |
| 背 | 脊中、中枢、筋缩、至阳、灵台、神道、身柱、陶道、大椎 |
| 项 | 哑门、风府 |
| 头 | 脑户、强间、后顶、百会、前顶、囟会、上星、神庭 |
| 面 / 口 | 素髎、水沟、兑端、龈交 |

顺序记忆：长强 → 腰俞 → 腰阳关 → 命门 → 悬枢 → 脊中 → 中枢 → 筋缩 → 至阳 → 灵台 → 神道 → 身柱 → 陶道 → 大椎 → 哑门 → 风府 → 脑户 → 强间 → 后顶 → 百会 → 前顶 → 囟会 → 上星 → 神庭 → 素髎 → 水沟 → 兑端 → 龈交。

## 原文骨架

> 任脉者，起于中极之下，以上毛际，循腹里，上关元，至咽喉，上颐循面入目。（《素问·骨空论》）

> 督脉者，起于下极之俞，并于脊里，上至风府，入属于脑。（《难经·二十八难》）

## 讲义强调（我的转述）

- 任督二脉一前一后，分别总任诸阴、总督诸阳。
- 任脉从会阴到承浆，督脉从长强到龈交；先记线路，再分段记穴位。
- 任督冲同起胞中，传统称“一源三岐”。
- 募穴、交会穴、络穴是学习穴位时的分类线索，不是自行治疗的按钮。
- 穴位定位、进针角度、深浅与手法必须经过专业训练；本页只做名称与顺序索引。
