# 切诊：脉诊与按诊

## 一句话结论

切诊包括脉诊与按诊。脉象是线索，不是算命；脉诊需要长期训练与四诊合参，按诊则看肌肤、手足、胸腹与穴位反应。

## 原文骨架

> 人一呼脉再动，一吸脉亦再动，呼吸定息脉五动，闰以太息，命曰平人。（《素问·平人气象论》）

> 平人之常气禀于胃，胃者平人之常气也；人无胃气曰逆，逆者死。（《素问·平人气象论》）

## 脉诊基础

- 寸口：常见分为寸、关、尺三部；左右手与脏腑的配对说法有流派差异，本页不展开。
- 常脉：有胃气、有神、有根；不是单纯的数字正常。
- 常见脉象：浮、沉、迟、数、虚、实、滑、涩。
- 脉象要看位置、频率、力量、流利度与整体状态。

## 常见脉象

| 脉象 | 传统观察点 |
| --- | --- |
| 浮 | 轻取即得，偏表 |
| 沉 | 重按始得，偏里 |
| 迟 | 频率偏慢 |
| 数 | 频率偏快 |
| 虚 | 力量不足 |
| 实 | 力量偏盛 |
| 滑 | 往来流利 |
| 涩 | 往来不畅 |

这些是传统脉象的分类语言，不能凭一两个脉象自行诊断。

## 按诊

- 肌肤：温度、润燥、肿胀。
- 手足：寒热、强弱。
- 胸腹：压痛、胀满、包块。
- 穴位：压痛、反应。
