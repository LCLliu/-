# 脏腑辨证：从总方向到具体位置

## 一句话结论

八纲定方向，脏腑辨证定位置：它把表里、寒热、虚实落到具体脏腑和脏腑关系上，依据的是藏象功能模型，不是解剖器官。

## 原文骨架

> 凡此十二官者，不得相失也。（《素问·灵兰秘典论》）

> 五脏所藏：心藏神，肺藏魄，肝藏魂，脾藏意，肾藏志。（《素问·宣明五气》）

> 六腑者，传化物而不藏，故实而不能满也。（《素问·五脏别论》）

> 夫治未病者，见肝之病，知肝传脾，当先实脾。（《金匮要略·脏腑经络先后病脉证第一》）

## 脏腑辨证的位置

1. 八纲先定总方向：表里、寒热、虚实。
2. 脏腑辨证再定位置：病在何脏、何腑，或哪些脏腑同病。
3. 看关系与传变：表里配对、生克乘侮、气血津液运行。
4. 与相似证候鉴别，标出反证与待补信息。
5. 形成可修正的证候假设。

脏腑辨证的系统化主要在后世完成；《内经》提供藏象与病证描述，《金匮》等提供杂病与传变思路。它和六经辨证、卫气营血/三焦辨证是并列框架，不互相替代。

## 五脏：功能线索与原典病证

| 脏 | 藏象功能线索 | 原典病证摘述 |
| --- | --- | --- |
| 肝 | 主疏泄、藏血；在志为怒，在液为泪，开窍于目；主筋 | 胁下痛引少腹、易怒；虚则目耳不聪、易恐 |
| 心 | 主血脉、藏神；在志为喜，在液为汗，开窍于舌 | 胸中痛、胁支满、肩背臂内痛；虚则胸腹大、腰胁相引痛 |
| 脾 | 主运化、统血；在志为思，在液为涎，开窍于口；主肌肉四肢 | 身重、肌肉痿、足不收、抽搐、脚下痛；虚则腹满肠鸣、飧泄食不化 |
| 肺 | 主气、司呼吸，宣发肃降，通调水道；在志为悲，在液为涕，开窍于鼻；主皮毛 | 喘咳逆气、肩背痛、汗出；虚则少气不足以息、耳聋嗌干 |
| 肾 | 藏精、主水、纳气；在志为恐，在液为唾，开窍于耳及二阴；主骨生髓 | 腹大胫肿、喘咳身重、寝汗出、恶风；虚则胸腹痛、清厥、意不乐 |

说明：原典病证是传统模型中的描述，不是现代疾病诊断标准；表中“摘述”为学习概括，不替代原文。

常见证候名称（只作词汇入口）：

- 肝：肝气郁结、肝血虚、肝火上炎
- 心：心气虚、心血虚、心火亢盛
- 脾：脾气虚、脾阳虚、寒湿困脾
- 肺：肺气虚、肺阴虚、风寒犯肺、风热犯肺
- 肾：肾阳虚、肾阴虚、肾精不足

## 六腑：传化与通降

| 腑 | 功能要点 | 辨证线索方向 |
| --- | --- | --- |
| 胆 | 贮藏排泄胆汁，主决断 | 口苦、惊怯、胁胀；常与肝同论 |
| 胃 | 受纳腐熟，以降为和 | 胃脘胀痛、嗳气、恶心、食欲异常 |
| 小肠 | 受盛化物，泌别清浊 | 腹胀、腹痛、二便异常；多与脾胃、大肠同论 |
| 大肠 | 传化糟粕 | 便秘、泄泻、腹痛 |
| 膀胱 | 贮尿排尿 | 尿频、尿急、尿痛、排尿困难 |
| 三焦 | 通行元气、运行水液 | 水液代谢与气化；三焦辨证另属温病框架，不宜简单等同六腑 |

六腑病证常与“通降失常”有关，但“通”不等于自行使用泻法；具体治疗不在本站范围。

## 脏腑表里配对

六组表里：肺—大肠、心—小肠、脾—胃、肝—胆、肾—膀胱、心包—三焦。

- 表里是功能配合关系，不等同于解剖上的直接相连。
- 心包常与三焦相配，作为六脏六腑表里体系的一部分；脏腑辨证的核心仍是五脏六腑。
- 表里同病很常见：脏病可以及腑，腑病也可以影响脏。

## 脏腑关系

| 关系 | 功能联系 | 辨证提示 |
| --- | --- | --- |
| 肝—脾 | 疏泄与运化；木克土 | 情志与饮食相互影响，肝郁可影响脾运 |
| 心—肾 | 水火既济、精血互生 | 心悸失眠与腰膝酸软可同见，需合参 |
| 肺—脾—肾 | 水液代谢：肺通调、脾运化、肾主水 | 水肿、痰饮等问题常需三脏同看 |
| 肝—肺 | 气机升降：肝升肺降 | 气滞与咳嗽可相互影响 |
| 脾—胃 | 纳运相合、升降相因、燥湿相济 | 脾胃常同病，不能只盯一个 |

《金匮》“见肝之病，知肝传脾，当先实脾”讲的是传变与治未病思路，不是可以自行套用的处方原则。

## 一个虚构教学案例

- 情境：35 岁，工作压力大，近半年胃脘胀满、嗳气、食少、便溏、乏力；情绪紧张时加重（人物与情节均为虚构）。
- 望：舌淡红，苔薄白。
- 闻：语声偏低，无特殊气味。
- 问：食欲一般，大便偏溏，睡眠浅，压力大。
- 切：脉弦细。
- 八纲：病位在里；虚实夹杂，以脾气虚为本、气滞为标；寒热不显。
- 脏腑：脾与肝同病，课堂讨论方向为“肝郁脾虚”，需与单纯脾气虚、湿滞脾胃、胃热等鉴别。
- 鉴别：单纯脾气虚无明显弦脉与情志诱因；湿滞脾胃多见苔腻、口黏、脘腹痞满；胃热多见口臭、苔黄、脉数、喜冷饮。
- 待补：病程、饮食、二便、睡眠、既往病史、用药，以及胃镜、幽门螺杆菌等现代检查。
- 边界：课堂示例，不构成诊断，也不给出治疗。

## 常见误区

1. 一脏对一症状：胁痛不一定就是肝，咳嗽不一定只是肺。
2. 脏腑等于解剖器官：藏象是功能网络，不是器官病名。
3. 只看脏不看腑：脾胃、肝胆、肺大肠等表里关系常需同看。
4. 跳过八纲直接定位：没有表里寒热虚实的总方向，脏腑定位容易失去边界。
5. 用脏腑辨证替代现代医学检查：传统辨证不能替代必要的现代诊断。
